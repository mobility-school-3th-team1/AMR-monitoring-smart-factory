## 실행 전제: Docker Compose

| 파트 | 기동 | Compose·Dockerfile (현재 main 기준) |
| --- | --- | --- |
| **BE** | `cd BE` → `docker compose up --build` | **있음** — `BE/docker-compose.yml`, `BE/amr_control_system/Dockerfile` |
| **DAS&DB** | 프로젝트 루트 → `docker compose --env-file .env -f docker/docker-compose.yml up -d --build` | **있음** — `docker/docker-compose.yml`, `docker/node-red/`, `docker/mosquitto/` |
| **FE** | `cd FE` → `docker compose up --build` | **없을 수 있음** — 별도 브랜치 미병합. **없을 때만** 에이전트가 작성 |

### Docker 파일 작성 규칙 (FE·DB 공통)

1. 작업 시작 시 **반드시 존재 여부 확인:** `docker-compose.yml`, `Dockerfile`(및 `docker-compose.override.yml` 등).
2. **이미 있으면** 내용을 읽고 시연 MVP에 맞게 **수정만** 한다. 동일 경로에 **중복 생성·덮어쓰기 금지**.
3. **없을 때만** 신규 작성한다. 팀 미병합 브랜치에 이미 있다면 merge 후 재확인.
4. BE compose는 **이미 main에 있음** — BE 에이전트는 compose **신규 작성하지 않음**.

- 호스트 JDK·Node 직접 실행 금지. 검증은 compose 기동 후 브라우저.
- `localhost:포트` = compose **publish** 포트.
- 브라우저 MQTT: `VITE_MQTT_URL=ws://localhost:9001` (DAS Mosquitto WS **9001** publish, G4).
- Node-RED MQTT: 브로커 **1883** (`MQTT_PORT`, 컨테이너 `MQTT_Broker`).
