## 1. 화면 설계 개요

본 시스템은 BSA 배터리 팩 생산 공장 내 AMR 기반 물류 운영을 통합 관제하기 위한 웹 기반 대시보드이다. 공장 2D 평면도를 중심으로 AMR의 현재 위치, 이동 경로, 상태 이상, 충전 현황, 작업 이력을 시각화하여 운영자가 물류 흐름과 위험 상황을 실시간으로 파악할 수 있도록 구성한다. 각 화면은 스크롤을 금지하고, 주요 정보를 한 화면에서 확인할 수 있도록 설계한다.

### 데이터·실시간 연동

- AMR 상태·위치는 BE DB 스냅샷(`AMR_STATUS_LOG` 최신 행 per `amr_id`) 및 `GET /dashboard/summary`, `GET /amrs`를 따른다.
- 실시간 갱신은 `WS /api/v1/stream`(`amrs.position.updated`, `amrs.status.updated`, `dashboard.summary.updated` 등)과 REST 조회를 혼합한다(`docs/API 정의.md` §8·§10).
- 비상 정지 UI·처리 순서는 `docs/ADR/20260518-1252-AMR-emergency-logic.md`를 따른다. FE가 단독으로 운행 상태를 변경하지 않는다.

# SCR-01. 메인 대시보드

## 화면 목적

공장 전체의 AMR 위치, 이동 경로, 환경 상태, 주요 알람, 실시간 작업 로그를 한 화면에서 확인하는 통합 관제 화면이다.

## Annotation

| 번호 | 객체 | 설명 |
| --- | --- | --- |
| ① | 공장 평면도 | 공장 구조와 AMR 현재 위치를 표시 |
| ② | AMR 상태 아이콘 | 장비 ID, 배터리, 상태를 표시하며 클릭 시 상세 화면 이동 |
| ③ | 환경 현황 영역 | 구역별 온도/습도/미세먼지 정보를 표시(`GET /environment/areas/current`) |
| ④ | 상태 요약 카드 | 운영 중·대기·충전 중·에러 AMR 대수. 에러 칸은 합계 수치 아래 미해결 건수를 별도 표기(`GET /dashboard/summary`) |
| ⑤ | 실시간 중요 알람 | 충돌, 고장, 경로 이탈 등 위험 이벤트 표시 |
| ⑥ | 실시간 작업 로그 | 작업 시작, 이동, 충전 등의 이벤트 로그 표시 |

## A. AMR 위치 및 상태 모니터링

### 와이어프레임 구성

공장 레이아웃을 기반으로 AMR의 현재 위치와 이동 경로를 표시한다. 각 구역은 생산 라인 및 창고 단위로 구분되며, 장비의 현재 상태를 직관적으로 파악할 수 있도록 설계한다.

### 객체 표시

각 AMR은 장비 ID와 배터리 잔량을 포함한 상태 정보와 함께 표시된다. 상태에 따라 색상을 구분하여 운행, 대기, 충전, 오류 상태를 시각적으로 표현한다.

### 사용자 인터랙션

운영자가 특정 장비를 클릭하면 개별 관제 화면으로 이동하여 상세 상태 및 작업 정보를 확인할 수 있도록 구성한다.

## B. 공장 환경 및 위험 감시

### 데이터 시각화

공장 구역별 온도, 습도, 미세먼지 데이터를 표시하며, 기준치를 초과하는 경우 색상 강조를 통해 이상 상태를 즉시 식별할 수 있도록 설계한다.

### 사고 예방

환경 데이터와 AMR 오류 데이터를 연계하여 특정 구역에서 반복적으로 발생하는 위험 상황을 감시할 수 있도록 구성한다.

## C. 실시간 알람 및 작업 로그

### 알람 표시

충돌 감지, 경로 이탈, 기능 고장 등의 중요 이벤트를 우선순위 기반으로 표시하여 운영자가 즉시 대응할 수 있도록 설계한다.

### 작업 로그

AMR의 이동 시작, 작업 재할당, 충전 시작 등의 이벤트 로그를 시간순으로 표시한다.

## 사용자 인터랙션

- 운영자가 AMR 아이콘을 클릭하면 개별 관제 화면(SCR-03)으로 이동한다.
- 실시간 중요 알람 클릭 시 관련 장비 및 위험 위치를 강조 표시한다.
- 환경 현황 영역 Hover 시 상세 환경 수치 정보를 표시한다.
- 상태 요약 카드 클릭 시 해당 상태 장비만 필터링하여 표시한다.
- 실시간 작업 로그 클릭 시 해당 작업 이력을 작업 이력 화면에서 조회할 수 있도록 설계한다.

### AMR 운행 상태와 API 매핑

| UI 표시 | DB/API `status` | 비고 |
| --- | --- | --- |
| 운행 중 | `OPERATING` | 요약 API `amrOperating` |
| 대기 중 | `IDLE` | 요약 API `amrWaiting` |
| 충전 중 | `CHARGING` | 요약 API `amrCharging` |
| 오류 발생 | `ERROR` | `faultCode` 참조. AMR 자체 진단 고장 |
| 비상 정지 | `EMERGENCY_STOP` | `emergencyStop` 명령 DB 반영 후. 고장(`ERROR`)과 구분 |

`status = ERROR`일 때 `faultCode`(API) / `fault_code`(DB): `SENSOR_FAULT`, `COMM_LOST`, `COLLISION`, `OVERLOAD`, `LOAD_IMBALANCE`, `DRIVE_FAULT`, `NAVIGATION_FAULT` (AMR 온보드 진단 가능 범위).

### 에러 요약 카드 표시 (④ 중 에러 칸)

| 표시 | API 필드 | 집계 규칙 |
| --- | --- | --- |
| 주 수치(에러) | `amrError` | 최신 스냅샷에서 `status IN ('ERROR', 'EMERGENCY_STOP')` |
| 하위 문구(미해결 n건) | `amrErrorUnresolved` | 미복구 `ERROR` + 비상 정지 조치가 필요한 `EMERGENCY_STOP` (집계 규칙은 `docs/API 정의.md` §2) |

## 상태 표시 규칙

| 상태 | 표시 방식 |
| --- | --- |
| 운행 중 | 초록색 상태 표시 |
| 대기 중 | 주황색 상태 표시 |
| 충전 중 | 파란색 상태 표시 |
| 오류 발생 | 빨간색 상태 표시 및 강조 |
| 비상 정지 | 빨간색 점멸 및 경고 문구 표시 |
| 배터리 20% 이하 | 배터리 영역 주황색 경고 표시 |
| 미세먼지 기준 초과 | 해당 구역 배경 강조 |
| 위험 알람 발생 | 알람 리스트 상단 우선 표시 |

# SCR-02. AMR 전체 관리

## 화면 목적

전체 AMR의 운영 상태와 현재 작업 현황을 통합 모니터링하고, 장비별 상태·위치·배터리·오류 정보를 실시간으로 확인하기 위한 관리 화면이다.

### Annotation

| 번호 | 객체 | 설명 |
| --- | --- | --- |
| ① | AMR 선택 목록 | 전체 장비 목록과 상태 정보를 표시하며 선택 시 상세 화면 이동 |
| ② | 상태 요약 카드 | 운영 중·대기·충전 중·에러 AMR 대수. 에러 칸은 SCR-01 ④와 동일(합계·미해결 하위 표기, `GET /dashboard/summary`) |
| ③ | 일별 오류 발생 건수 차트 | `GET /analytics/kpis?groupBy=day`의 `errorCount` 시계열 |
| ④ | 평균 시간 준수율 차트 | `GET /analytics/kpis?groupBy=day`의 `scheduleComplianceRate` 시계열 |
| ⑤ | 건전성 기준 미달 기체 영역 | 점검 필요 장비 및 최근 점검 정보를 표시 |
| ⑥ | AMR 현재 위치 및 상태 목록 | 장비 상태, 현재 위치, 목적지, 작업 상태를 테이블 형태로 표시 |

## A. AMR 상태 통합 모니터링

### 와이어프레임 구성

좌측 영역에는 AMR 선택 목록을 배치하고, 우측 영역에는 운영 상태 요약 카드와 통계 차트, 장비 상태 목록 테이블을 배치하여 전체 운영 현황을 한눈에 확인할 수 있도록 구성한다.

### 객체 표시

각 AMR은 장비 ID, 배터리 상태, 현재 위치, 목적지, 운영 상태와 함께 표시된다. 상태에 따라 색상을 구분하여 운행, 대기, 충전, 오류 상태를 직관적으로 식별할 수 있도록 설계한다.

### 사용자 인터랙션

운영자가 특정 장비를 클릭하면 개별 관제 화면(SCR-03)으로 이동하여 상세 상태 및 작업 정보를 확인할 수 있도록 구성한다.

## B. 운영 통계 및 분석

### 데이터 시각화

일별 오류 발생 건수, 평균 시간 준수율 데이터를 차트 형태로 시각화하여 이상 발생 추이와 작업 일정 준수 상태를 직관적으로 파악할 수 있도록 설계한다.

### 운영 분석

오류 발생 빈도가 높은 기간과 시간 준수율 저하 구간을 비교하여 운영 이상 요소를 식별할 수 있도록 구성한다.

## C. 장비 상태 및 건전성 관리

### 상태 목록 표시

전체 AMR의 상태, 배터리 잔량, 현재 위치, 목적지, 현재 작업, 이동 속도를 테이블 형태로 표시한다.

### 건전성 모니터링

건전성 기준 미달 장비 수와 최근 점검 대상 장비를 표시하여 운영자가 점검 필요 장비를 빠르게 확인할 수 있도록 설계한다.

## 사용자 인터랙션

- AMR 선택 목록 클릭 시 해당 장비의 상세 화면(SCR-03)으로 이동한다.
- 상태 요약 카드 클릭 시 해당 상태의 장비만 필터링하여 표시한다.
- 차트 Hover 시 상세 수치를 표시한다.
- 상태 목록 테이블 클릭 시 해당 장비의 현재 작업 및 위치 정보를 강조 표시한다.
- 오류 상태 장비 선택 시 관련 오류 정보를 우선 표시한다.

## 상태 표시 규칙

| 상태 | 표시 방식 |
| --- | --- |
| 운행 중 | 초록색 상태 표시 |
| 대기 중 | 주황색 상태 표시 |
| 충전 중 | 파란색 상태 표시 |
| 오류 발생 | 빨간색 상태 표시 및 강조 |
| 건전성 기준 미달 | 경고 문구 및 강조 표시 |
| 배터리 20% 이하 | 배터리 영역 주황색 경고 표시 |
| 점검 필요 장비 | 최근 점검 대상 영역 강조 |
| 오류 다발 장비 | 오류 횟수 기반 우선 표시 |

# SCR-03. AMR 개별 관제

## 화면 목적

선택한 AMR의 상세 상태와 작업 정보를 실시간으로 모니터링하고, 센서·구동부 상태 및 운영 이력을 확인하여 이상 상황 발생 시 즉각적인 대응이 가능하도록 지원하는 개별 관제 화면이다.

## Annotation

| 번호 | 객체 | 설명 |
| --- | --- | --- |
| ① | AMR 리스트 | 전체 장비 목록 및 현재 선택된 장비 상태 표시 |
| ② | 상태 요약 카드 | 운영 중·대기·충전 중·에러 AMR 대수. 에러 칸은 SCR-01 ④와 동일(합계·미해결 하위 표기, `GET /dashboard/summary`) |
| ③ | 장비 상세 정보 영역 | 현재 작업, 배터리, 온도, 습도 정보를 표시 |
| ④ | 총 주행 거리 영역 | 누적 주행 거리(`GET /amrs/{amrId}`·`AMR_MASTER.total_mileage`) |
| ⑤ | 오류 상태 및 비상 정지 버튼 | 현재 오류 상태 표시 및 비상 정지 기능 제공 |
| ⑥ | 장비·센서 상태 영역 | BE 제공 항목만 표시(위치·적재·배터리·SoH 등, `GET /amrs/{amrId}`) |
| ⑦ | 시간 준수율 추이 차트 | `GET /analytics/kpis?groupBy=day`의 `scheduleComplianceRate` (SCR-02 ④와 동일 API) |

## A. AMR 상세 상태 모니터링

### 와이어프레임 구성

좌측에는 AMR 선택 리스트를 배치하고, 우측에는 선택된 장비의 상세 정보와 운영 상태, 센서 상태, 운영 이력 차트를 배치하여 장비 상태를 종합적으로 확인할 수 있도록 구성한다.

### 객체 표시

선택된 AMR의 장비 ID, 현재 작업 상태, 배터리 상태, 온도, 습도 정보를 표시한다. 운영 상태에 따라 색상을 구분하여 정상 운행 여부를 직관적으로 식별할 수 있도록 설계한다.

### 사용자 인터랙션

운영자가 좌측 장비 리스트에서 특정 장비를 선택하면 해당 장비의 상세 정보 및 상태 데이터가 우측 영역에 표시되도록 구성한다.

## B. 장비·센서 상태 (BE 제공 범위)

### 데이터 시각화

`GET /amrs/{amrId}` 및 `AMR_STATUS_LOG`에 정의된 항목만 표시한다. 예: 위치·구역(`position`), 적재(`loadWeightKg`), 배터리·SoH·배터리 온도, `faultCode`·`faultMessage`(ERROR 시).

LiDAR·전·후방 카메라 등 **온보드 센서 개별 상태는 본 프로젝트 범위 외**이며 화면에 배치하지 않는다.

### 상태 감시

`status`가 `ERROR`이거나 `faultCode`가 있는 경우 해당 영역을 강조 표시한다.

## C. 운영 이력 및 작업 분석

### 운영 정보 표시

누적 주행 거리를 표시하여 장비의 누적 운행 이력을 확인할 수 있도록 구성한다.

### 시간 준수율 분석

`GET /analytics/kpis?groupBy=day`의 `scheduleComplianceRate`를 그래프로 시각화한다(SCR-02 ④와 동일 데이터).

## D. 비상 제어 및 오류 대응

### 오류 상태 표시

현재 발생한 오류 상태를 상단 영역에 표시하여 운영자가 즉시 위험 상황을 인지할 수 있도록 구성한다.

### 비상 정지 기능

비상 상황 발생 시 운영자가 특정 AMR을 즉시 정지할 수 있도록 비상 정지(E-Stop) 기능을 제공한다.

## 사용자 인터랙션

- AMR 리스트 클릭 시 해당 장비의 상세 정보로 화면이 갱신된다.
- 비상 정지 버튼: 확인 팝업 후 `POST /api/v1/amrs/{amrId}/commands` (`emergencyStop`) 호출 → HTTP `accepted: true` 수신 후 DAS MQTT 정지 고지 → UI는 REST/WebSocket으로 `EMERGENCY_STOP` 반영. FE 단독으로 상태를 바꾸지 않는다.
- 장비·센서 영역 Hover 시 `GET /amrs/{amrId}` 상세 수치를 표시한다.
- 시간 준수율 차트 Hover 시 날짜별 상세 수치를 표시한다.
- 오류 상태 장비 선택 시 관련 오류 내용을 우선 표시한다.

## 상태 표시 규칙

| 상태 | 표시 방식 |
| --- | --- |
| 정상 운행 | 초록색 상태 표시 |
| 대기 상태 | 주황색 상태 표시 |
| 오류 발생 | 빨간색 상태 표시 및 강조 |
| 비상 정지 | 빨간색 점멸 및 경고 문구 표시 |
| 배터리 20% 이하 | 배터리 영역 주황색 경고 표시 |
| 고장(ERROR) | `faultCode`·`faultMessage` 강조 표시 |
| 점검 필요 | `AMR_MASTER.inspection_dt` 기준 경고 문구 표시 |

# SCR-04. AMR 배터리 및 충전 스테이션 현황

## 화면 목적

충전 스테이션 운영 상태와 AMR의 배터리 현황을 실시간으로 모니터링하고, 충전 병목 및 저전력 위험 상황을 사전에 파악하여 안정적인 물류 운영을 지원하는 화면이다.

## Annotation

| 번호 | 객체 | 설명 |
| --- | --- | --- |
| ① | 충전 운영 요약 카드 | 운영 충전 스테이션 수 및 상태 요약 표시 |
| ② | 충전 중 AMR 카드 | 현재 충전 중인 장비 수 표시 |
| ③ | 평균 충전률 카드 | 전체 장비 평균 충전률 표시 |
| ④ | 완충 예상 시간 카드 | 가장 오래 걸리는 장비 기준 예상 충전 시간 표시 |
| ⑤ | 충전 스테이션 상세 영역 | 스테이션별 연결 장비 및 충전 상태 표시 |
| ⑥ | 충전 대기열 테이블 | 스테이션별 충전 대기 및 예상 완충 정보 표시 |
| ⑦ | 충전 완료 예상 차트 | 충전 완료 시간 분포를 시각화 |
| ⑧ | 충전 스테이션 알림 영역 | 혼잡 상태 및 충전 관련 경고 표시 |

## A. 충전 스테이션 운영 현황

### 와이어프레임 구성

상단에는 충전 운영 요약 카드를 배치하고, 중앙에는 충전 스테이션별 상세 상태 영역을 구성한다. 하단에는 충전 대기열, 충전 완료 예상 차트 및 충전 알림 영역을 배치하여 충전 운영 상황을 종합적으로 확인할 수 있도록 설계한다.

### 객체 표시

각 충전 스테이션은 연결된 AMR 수, 충전 상태, 평균 충전률과 함께 표시된다. 충전 혼잡 상태 발생 시 색상 강조를 통해 운영자가 즉시 인지할 수 있도록 구성한다.

### 사용자 인터랙션

운영자가 특정 충전 스테이션을 선택하면 해당 스테이션에 연결된 AMR 및 충전 상태 정보를 상세 조회할 수 있도록 구성한다.

## B. 배터리 및 충전 상태 모니터링

### 데이터 시각화

AMR의 배터리 잔량과 예상 완충 시간을 표시하며, 충전 상태를 충전 중·대기·완료 상태로 구분하여 시각화한다.

### 충전 병목 감시

충전 스테이션 사용률과 충전 대기열 데이터를 기반으로 혼잡 상태를 감시하고, 특정 스테이션에 과도한 충전 요청이 집중되는 상황을 식별할 수 있도록 설계한다.

## C. 충전 완료 예측 및 운영 분석

### 충전 완료 예측

충전 완료 예상 차트를 통해 30분 이내, 1시간 이내, 1시간 초과 장비 수를 시각적으로 표시하여 운영자가 충전 스케줄을 빠르게 파악할 수 있도록 구성한다.

### 운영 효율 분석

충전 대기 시간과 충전소 사용 현황을 기반으로 충전 스테이션 운영 효율을 분석할 수 있도록 설계한다.

## D. 충전 알림 및 위험 대응

### 충전 알림 표시

충전 스테이션 혼잡, 저전력 우선 충전, 충전 지연 등의 이벤트를 알림 형태로 표시하여 운영자가 즉시 대응할 수 있도록 구성한다.

### 위험 상황 감시

배터리 부족 상태가 지속되거나 충전 완료 예상 시간이 과도하게 증가하는 경우 경고 상태를 표시하도록 설계한다.

## 사용자 인터랙션

- 충전 스테이션 클릭 시 해당 스테이션의 연결 장비 정보를 강조 표시한다.
- 충전 대기열 테이블 클릭 시 해당 AMR의 상세 정보 화면(SCR-03)으로 이동한다.
- 충전 완료 예상 차트 Hover 시 상세 수치를 표시한다.
- 충전 알림 클릭 시 관련 충전 스테이션 또는 장비를 강조 표시한다.
- 혼잡 상태 충전소 선택 시 대기열 정보를 우선 표시한다.

## 상태 표시 규칙

| 상태 | 표시 방식 |
| --- | --- |
| 정상 운영 | 초록색 상태 표시 |
| 충전 중 | 파란색 상태 표시 |
| 충전 대기 | 주황색 상태 표시 |
| 충전 혼잡 | 주황색 또는 빨간색 강조 |
| 배터리 20% 이하 | 배터리 영역 빨간색 경고 표시 |
| 저전압 우선 충전 | 경고 문구 표시 |
| 충전 지연 | 예상 완충 시간 강조 표시 |
| 충전 스테이션 오류 | 빨간색 상태 표시 및 알림 출력 |

# SCR-05. 작업 이력 및 분석

## 화면 목적

AMR의 작업 수행 이력과 운영 데이터를 분석하여 작업량, 이동 거리, 작업 시간 및 장비별 운영 효율을 확인하고, 물류 운영 상태를 종합적으로 분석하기 위한 화면이다.

## Annotation

| 번호 | 객체 | 설명 |
| --- | --- | --- |
| ① | 작업 요약 카드 | 일별 작업 건수, 이동 거리, 총 작업 시간, 평균 작업 시간 표시 |
| ② | 시간대별 작업 건수 차트 | `GET /analytics/workload?groupBy=hour` |
| ③ | AMR별 작업 비중 차트 | `GET /analytics/workload?groupBy=amr` |
| ④ | 작업 내역 목록 테이블 | `GET /work-histories` (출발지·도착지·작업 상태 등) |
| ⑤ | 일별 작업 요약 테이블 | 최근 기간 작업 건수 추이 및 전일 대비 변화 표시 |

## A. 작업 운영 현황 모니터링

### 와이어프레임 구성

상단에는 작업 요약 카드를 배치하고, 중앙에는 시간대별 작업량 차트와 AMR별 작업 비중 차트를 배치한다. 하단에는 작업 내역 테이블과 일별 작업 요약 테이블을 구성하여 작업 흐름과 운영 데이터를 종합적으로 확인할 수 있도록 설계한다.

### 객체 표시

작업 건수, 이동 거리, 총 작업 시간, 평균 작업 시간 데이터를 요약 카드 형태로 표시하며, 운영 변화 추이를 직관적으로 파악할 수 있도록 증감률 정보를 함께 제공한다.

### 사용자 인터랙션

운영자가 특정 작업 내역을 선택하면 해당 AMR의 작업 상태와 이동 이력을 확인할 수 있도록 구성한다.

## B. 작업량 및 운영 효율 분석

### 데이터 시각화

시간대별 작업 건수와 장비별 작업 비중 데이터를 차트 형태로 시각화하여 특정 시간대의 작업 집중도와 장비 운영 비율을 확인할 수 있도록 설계한다.

### 운영 분석

작업량이 집중되는 시간대와 특정 AMR의 작업 비중을 분석하여 운영 효율 및 병목 가능성을 파악할 수 있도록 구성한다.

## C. 작업 이력 조회 및 상태 관리

### 작업 이력 표시

작업 시간, AMR ID, 작업 유형, 출발지, 도착지, 작업 내용 및 상태 정보를 테이블 형태로 표시하여 작업 흐름을 상세하게 조회할 수 있도록 구성한다.

### 상태 추적

운반, 충전, 대기 상태를 구분하여 표시하고, 특정 작업 상태를 빠르게 식별할 수 있도록 설계한다.

## D. 작업 추이 및 변화 분석

### 작업 추이 표시

최근 기간의 작업 건수 데이터를 일별 요약 테이블 형태로 표시하여 운영량 변화를 확인할 수 있도록 구성한다.

### 변화율 분석

전일 대비 작업 증가율 또는 감소율을 표시하여 운영 변화 추이를 직관적으로 파악할 수 있도록 설계한다.

## 사용자 인터랙션

- 작업 내역 테이블 클릭 시 해당 AMR의 상세 정보 화면(SCR-03)으로 이동한다.
- 시간대별 작업 건수 차트 Hover 시 시간대별 상세 수치를 표시한다.
- 작업 비중 차트 Hover 시 장비별 작업 비율 정보를 표시한다.
- 작업 상태 필터 선택 시 해당 상태의 작업만 조회할 수 있도록 구성한다.
- 일별 작업 요약 클릭 시 해당 날짜의 작업 이력을 상세 조회할 수 있도록 설계한다.

| 충전 중 | 파란색 상태 표시 |
